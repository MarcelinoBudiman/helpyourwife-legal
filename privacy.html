Privacy Policy

Effective 25 November 2026

Summary

The helpyourwife upload tool is a private script used only by the owner of the @helpyourwife accounts. It does not collect, sell, or share personal data from anyone else.

What the tool accesses

When the owner authorizes it, the tool receives access tokens for the owner's own accounts and uses them only to upload videos:

  • TikTok: basic profile info (user.info.basic) and video upload (video.upload)
  • YouTube: video upload (youtube.upload)
  • Instagram: account info and Reels publishing (instagram_basic, instagram_content_publish, pages_show_list, pages_read_engagement)

Where data is stored

Access tokens are stored only in a local file on the owner's computer. They are not sent to any server other than the official TikTok, Google, and Meta APIs. The tool has no database, no analytics, no cookies, and no advertising.

Viewers

The tool does not read or store information about people who watch, like, or comment on the videos. Viewer data is handled by TikTok, YouTube, and Instagram under their own privacy policies.

Revoking access

The owner can revoke the tool's access at any time from the connected apps settings of each platform, and can delete the local token file.

This website

This site is hosted on GitHub Pages and sets no cookies. GitHub may log basic request data such as IP addresses for security, as described in GitHub's privacy statement.

Changes

This policy may be updated. The effective date at the top of this page changes when it is.

Contact

Privacy questions can be sent by opening an issue on this site's GitHub repository.
